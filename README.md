# لوحة لغة الإشارة

موقع ثابت (HTML واحد) لعمل لوحات لغة الإشارة وطباعتها على ورق A4.

## التشغيل المحلي
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. ارفع محتويات الفولدر ده على repository جديد.
2. من **Settings → Pages**.
3. في **Source** اختار **Deploy from a branch**، وبعدين Branch: `main` والفولدر `/ (root)`.
4. استنى دقيقة وهيظهر الرابط: `https://USERNAME.github.io/REPO-NAME/`

> الموقع بيحتاج إنترنت علشان يحمّل Tailwind والخطوط وFont Awesome وinteract.js من الـ CDN.

## الكاميرا
- كل خانة فيها زرارين: **كاميرا** (تصوير مباشر) و**ملف** (اختيار صورة من الجهاز).
- الصورة بتتصور **من غير عكس** (اليمين يفضل يمين والشمال يفضل شمال) حتى مع الكاميرا الأمامية، والمعاينة مطابقة للصورة النهائية.
- الكاميرا المباشرة بتحتاج إذن المتصفح، وبتشتغل على الروابط `https://` (زي GitHub Pages) أو `localhost`.
- لو الإذن اترفض أو المتصفح مش بيدعمها، الموقع بيفتح كاميرا الجهاز الأصلية (على الموبايل) كبديل.

## الحفظ التلقائي
- الموقع بيحفظ شغلك تلقائيًا في المتصفح (IndexedDB): الصور، الأسهم، ضبط الصورة، الخانات المكررة، الصفحات والخانات الحرة ونصوصها.
- لو عملت ريفريش أو قفلت الصفحة ورجعت، كل حاجة بترجع زي ما كانت.
- الحفظ على نفس المتصفح والجهاز بس (مش بيتنقل بين الأجهزة). ومش بيشتغل في وضع التصفح الخفي.
- زرار سلة المهملات (تحت زرار الطباعة) بيمسح كل حاجة ويبدأ من جديد.

## الموبايل والكمبيوتر
- على الشاشات الصغيرة (أقل من 820px) الصفحات بتتحول لعمودين وتملى عرض الشاشة، والصفحة الحرة ليها تمرير داخلي.
- على الكمبيوتر والطباعة الشكل بيفضل A4 زي ما هو.
